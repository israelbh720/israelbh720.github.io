# Portfólio — Israel Carlos de Aguiar

## Como personalizar

1. Abra `index.html`.
2. Troque `SEU_EMAIL_AQUI` pelo seu e-mail.
3. Troque `55SEUNUMERO` pelo seu WhatsApp no formato internacional, somente números.
4. Coloque seu currículo em PDF dentro de `assets/docs/` com o nome:
   `curriculo-israel.pdf`
5. Coloque suas fotos em `assets/img/`:
   - projeto-1.jpg
   - projeto-2.jpg
   - projeto-3.jpg
6. Coloque seu vídeo em:
   `assets/videos/projeto-demo.mp4`
7. Se quiser, altere os textos dos projetos diretamente no `index.html`.

## Publicação

Este site é estático e pode ser hospedado gratuitamente em serviços como GitHub Pages, Netlify ou Vercel.

Depois de publicado, você terá um link para colocar no currículo e compartilhar com recrutadores.
