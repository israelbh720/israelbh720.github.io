# Publicação no GitHub Pages

1. Crie uma conta no GitHub em https://github.com/
2. Crie um repositório público chamado `portfolio`.
3. Envie TODOS os arquivos e pastas deste projeto para o repositório.
4. No repositório, abra Settings > Pages.
5. Em "Build and deployment", escolha "Deploy from a branch".
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Clique em Save.
8. Aguarde a publicação.

O endereço ficará aproximadamente:
https://SEU-USUARIO.github.io/portfolio/

Importante:
- O arquivo inicial é `index.html`.
- O arquivo `.nojekyll` já está incluído.
- Coloque fotos em `assets/img/`.
- Coloque vídeos MP4 em `assets/videos/`.
- Coloque o currículo em `assets/docs/curriculo-israel.pdf`.
- Antes de publicar, altere o e-mail, WhatsApp e GitHub no `index.html`.

Para um site de perfil, outra opção é criar um repositório chamado exatamente `SEU-USUARIO.github.io`; nesse caso, o endereço fica:
https://SEU-USUARIO.github.io/
